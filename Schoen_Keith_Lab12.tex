\section{Security Event Triage Memorandum}

\medskip
\textbf{\textcolor{headercol}{1.\enspace Engagement Overview}}\\
Greater Denver Health Partners requested forensic triage of a suspected security event on an internal Windows host.
Evidence was provided as a Windows Event Log export (.evtx) and received by the examining analyst on 2026-05-04.
Analysis was conducted per the scenario brief supplied by the client.

\medskip
\textbf{\textcolor{headercol}{2.\enspace What Was Examined}}\\
\textbf{Filename:} \texttt{psexec-system-execution.evtx} --- sourced from the \texttt{Microsoft-Windows-Sysmon\\/Operational}
channel on host \texttt{fs03vuln.offsec.lan} (offsec.lan domain).
SHA-256 hash recorded at intake: \texttt{2652560B\ldots{}874039886} (see Chain of Custody log).
Key Event Record IDs examined: 48595, 48596, 48601, and 48605; spanning 2021-12-04T21:17:29Z -- 2021-12-04T21:19:16Z.

\medskip
\textbf{\textcolor{headercol}{3.\enspace Findings}}\\
Evidence indicates a threat actor conducted lateral movement onto \texttt{fs03vuln.offsec.lan} using PsExec.
At 21:17:29Z (EID~48595), \texttt{PsExec64.exe} --- run from \texttt{C:\textbackslash TOOLS\textbackslash} on an attacker-controlled host ---
dropped the service binary \texttt{PSEXESVC.exe} into \texttt{C:\textbackslash Windows\textbackslash} on the target via SMB Admin Share.
Immediately following (EID~48596), the Windows Service Control Manager wrote the PSEXESVC service entry to the
registry with a demand-start value (DWORD \texttt{0x3}), confirming installation.
At 21:19:16Z, \texttt{PSEXESVC.exe} created a named pipe (EID~48601) and \texttt{PsExec64.exe} connected to it
(EID~48605), completing a remote command execution session.
All activity ran under \texttt{S-1-5-18} (SYSTEM), indicating the attacker operated with the highest available local privilege.
(See IOC Log and ATT\&CK Mapping on following pages.)\\

\medskip
\textbf{\textcolor{headercol}{5.\enspace Recommendations}}\\
IT leadership should hunt across all domain-joined workstations for \texttt{PSEXESVC.exe} in \texttt{C:\textbackslash Windows\textbackslash}
and the registry key \texttt{HKLM\textbackslash System\textbackslash CurrentControlSet\textbackslash Services\textbackslash PSEXESVC}, both reliable indicators of PsExec lateral movement.
Sysmon EID 17/18 queries filtered for pipe names matching \texttt{\textbackslash PSEXESVC-*} will surface any additional hosts where this technique executed.
Analysts should audit non-standard directories (e.g., \texttt{C:\textbackslash TOOLS\textbackslash}) for PsExec variants and review SMB logs for internal \texttt{ADMIN\$} share connections.
Any newly identified hosts should have their event logs preserved immediately before retention windows expire.
